# PERMANENT FIX PLAN — n8n on Render

## Problem

n8n di Render free tier terus bermasalah: setup page, "column User.role does not exist", 502 Bad Gateway, workflow hilang.

## Root Causes (8 ditemukan)

| # | Root Cause | Impact |
|---|---|---|
| **1** | `:stable` = floating tag, bukan pinned | **Schema mismatch setiap restart** ← PRIMARY KILLER |
| 2 | `N8N_BASIC_AUTH_*` deprecated di n8n v1.0+ | Gak ada efek, noise startup |
| 3 | Ephemeral filesystem | Config hilang setiap sleep |
| 4 | `NODE_OPTIONS=256MB` terlalu ketat di 512MB RAM | OOM crash → 502 |
| 5 | `N8N_METRICS=true` tanpa Prometheus | Buang memory percuma |
| 6 | `WEBHOOK_URL` trailing slash | Double-slash di webhook |
| 7 | DB host perlu full internal hostname | Connection gagal |
| 8 | Password hardcoded | Security risk |

## Cascade of Failures

```
render.yaml pakai :stable (floating tag)
  → Setiap restart, pull versi BERBEDA
    → Schema migration gagal ("column User.role does not exist")
      → n8n gagal start → 502 Bad Gateway
        → Kalau sempat start, encryption key gak match → setup page
```

## Implementation Plan (8 fixes)

```yaml
# BEFORE: docker.io/n8nio/n8n:stable
```
